OpenAL Soft 1.23.1 (sound)
--------------------------

           next to the program that uses them
  Licence: GNU Library General Public License, version 2 or later
           (OpenAL-Soft-COPYING.txt in this folder)
  Source:  https://github.com/kcat/openal-soft/tree/1.23.1
  Build:   from the Silk.NET.OpenAL.Soft.Native package, https://github.com/dotnet/Silk.NET

  The library is a separate file that the program loads when it starts. You may replace it
  with your own build of OpenAL Soft (same file name, same processor type); the program
  then uses that one.
